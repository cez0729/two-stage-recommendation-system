# All_Beauty 数据整理与切分分析

生成时间：2026-07-22

## 1. 数据来源

本次使用 McAuley Lab 发布的 Amazon Reviews 2023 `All_Beauty` 类别：

- 评论：701,528 行，压缩文件 94,441,517 字节。
- 商品元数据：112,590 行，压缩文件 39,871,253 字节。
- 两个文件均完整扫描；无损坏 JSON 行，无缺少必需字段的行。
- 文件来源、SHA-256 和字段列表见 `artifacts/raw_manifest.json`。

## 2. 清洗过程

| 步骤 | 剩余交互 | 含义 |
| --- | ---: | --- |
| 原始评论 | 701,528 | 下载文件中的全部评论 |
| 必需字段非空 | 701,528 | 用户、商品、时间和评分均存在 |
| 完全重复去除 | 694,252 | 同一用户、商品、时间只保留一条 |
| 用户-商品去重 | 693,929 | 同一用户多次评论同一商品，只保留最后一次 |
| 评分至少 3 星 | 550,471 | 将 3-5 星视为正向隐式反馈 |
| 迭代 5-core | 1,888 | 用户和商品均至少出现 5 次，反复过滤至稳定 |

5-core 一共经过 9 轮才稳定，说明该类别的交互图非常稀疏。最终得到：

- 198 位用户。
- 280 个商品。
- 1,888 条正向且去重后的交互。
- 280 个商品全部匹配到标题元数据。
- 时间范围：2018-12-13 至 2023-02-22（UTC）。

## 3. 数据分布

- 平均评分：4.502。
- 3 星 183 条，4 星 574 条，5 星 1,131 条。
- 每位用户平均 9.54 条交互，中位数 7，最少 5，最多 54。
- 每个商品平均 6.74 条交互，中位数 6，最少 5，最多 13。
- 交互主要集中在 2020 年（1,065 条）和 2021 年（725 条）。

## 4. 时间切分

每位用户按时间升序排列：

- `retrieval_train`：前面的历史行为，共 1,294 条，用于训练召回模型。
- `rank_train`：倒数第 3 次行为，共 198 条，用于训练精排模型。
- `validation`：倒数第 2 次行为，共 198 条，用于调参和早停。
- `test`：最后一次行为，共 198 条，只用于最终评估。

所有 198 位用户在四个阶段中都存在。自动检查确认：

- `retrieval_train < rank_train < validation < test` 对每位用户严格成立。
- rank、validation 和 test 的目标商品未出现在对应用户之前的历史中。

## 5. 结论与限制

第二、第三阶段的数据管道已经完整跑通，适合作为端到端开发和测试数据。但在严格 5-core 后只有 1,888 条交互，明显低于规格建议的 50 万条，因此不适合作为最终作品集模型的唯一训练数据。

后续模型开发可以先用该数据快速验证代码；在正式训练双塔和 LambdaRank 前，建议切换到更密集的类别。规格中的首选备选是 `Video_Games`，其原始评论压缩包约 814 MB、元数据约 103 MB，需要单独安排下载和计算时间。
