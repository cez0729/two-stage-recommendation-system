# 正式数据升级：Amazon Video_Games 5-core

生成时间：2026-07-22

## 1. 为什么更换数据

早期 `All_Beauty 2023` 在严格过滤后只有 198 位用户、280 个商品和 1,888 条交互。它足够验证代码，但不足以支撑有说服力的推荐模型实验。

正式数据改为 McAuley Lab 的 Amazon Reviews 2018 `Video_Games` 5-core：

- 评论文件：497,577 行，153,969,506 字节。
- 商品元数据：84,819 行，53,279,669 字节。
- 全文件扫描无损坏 JSON，无必需字段缺失。
- 评论 SHA-256：`a0bd63e90ad3bd577778678672bb2e7e88b8c085683c86aca2f18c1ab543cb84`。
- 元数据 SHA-256：`4069e17c7efa33e7574c2e77f1fe0b0c6f2a42a7ac29c4422696d788d8a8e0a6`。

官方来源：

- `https://mcauleylab.ucsd.edu/public_datasets/data/amazon_v2/categoryFilesSmall/Video_Games_5.json.gz`
- `https://mcauleylab.ucsd.edu/public_datasets/data/amazon_v2/metaFiles2/meta_Video_Games.json.gz`

## 2. 清洗结果

| 步骤 | 剩余交互 |
| --- | ---: |
| 原始评论 | 497,577 |
| 必需字段非空 | 497,577 |
| 完全重复去除 | 473,824 |
| 用户-商品去重 | 473,427 |
| 只保留 3-5 星 | 421,505 |
| 再次迭代 5-core | 362,782 |

清洗稳定后有 40,771 位用户、14,489 个商品。14,475 个商品匹配到标题，14 个缺失标题被保留并标记为空。

## 3. 日级时间戳处理

该数据的 `unixReviewTime` 只精确到日期。同一用户同一天评论多个商品时，无法证明当天的先后顺序。直接按商品 ID 排序会制造虚假的时间信息。

本项目采用保守规则：

1. 按每个用户的不同日期排序。
2. 最后三个不同日期分别作为 rank、validation 和 test。
3. 每个目标日期确定性保留一个商品作为单目标。
4. 同日其他目标商品因顺序不明而剔除。
5. 目标日前至少有两条历史、且至少存在四个不同日期的用户才进入评估。

结果：

- 19,621 位用户进入严格时间评估。
- 21,150 位用户因不同日期不足被排除。
- 19,900 条同日歧义目标被排除。
- `retrieval_train`：138,734 条。
- `rank_train`、`validation`、`test`：各 19,621 条。
- 最终共 197,597 条交互、14,391 个商品。
- 自动检查确认严格时间递增，目标商品不在历史中。

## 4. 相比旧数据的收益

| 指标 | All_Beauty 小数据 | Video_Games 正式数据 | 倍数 |
| --- | ---: | ---: | ---: |
| 可评估用户 | 198 | 19,621 | 99.1× |
| 严格切分交互 | 1,888 | 197,597 | 104.7× |
| 商品 | 280 | 14,391 | 51.4× |

这使双塔训练、FAISS索引、性能测试、分组评估和统计置信区间真正具有展示价值。

## 5. 限制

- 数据来自2018版本而非2023版本，报告和简历必须写清楚。
- 官方文件本身已经做过5-core；本项目在评分过滤和去重后再次执行迭代5-core。
- 时间只有日级精度，项目采用保守剔除而非虚构日内顺序。
- 这是公开离线数据，不能声称真实线上收益或A/B测试效果。

数据来源相关研究：He and McAuley (2016), [Ups and Downs](https://doi.org/10.1145/2872427.2883037)。
